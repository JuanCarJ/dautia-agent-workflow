# Execution profiles · r3

Canonical policy: `../config/routing-policy.json`. Default principal and worker:
`sol_high` = `gpt-5.6-sol` / `high`. Do not automatically downgrade to medium.
Skills and role procedures do not select model brands. Implementation, routine
test writing, Git and resolved operations remain Sol high.

For a bounded analysis, eligible profiles are Sol high, Astra low and Astra medium,
filtered by role/effect, verified capabilities, host availability and budget BEFORE
using a recommendation. Never let Jev add a profile excluded by those rules.
Return an analytical decision to the principal; the Sol executor implements it.
No automatic Astra writer/operator fallback. Do not relabel a writer as analyst.

The initial Jev questions distinguish missing accessible information, unresolved
decisions, reasoning depth and material contradictions. Routine/focal work can
stay Sol; coupled decisions/deep causes/multiple conflicts can recommend Astra.
This mapping is a hypothesis for evaluation, not a proved model ranking. Unknown
or insufficient evidence produces retrieval/abstention, not automatic escalation.

`sol_medium`, `sol_xhigh` and `astra_high` are explicit-only candidates. A supported
user request can override a savings preference within its exact analytical scope;
a hard denied profile/capability still blocks it. No silent downgrade. No profile
request changes permissions, target, acceptance or principal family by itself.
Explicit Astra product writing is outside this automatic policy and requires a
separate policy/authority decision, not a router response.

Adapters are generated from canonical roles at installation. Ordinary names are
pinned to Sol high even if the parent is Astra. Read-only analytical variants use
`ROLE__astra_low`, `ROLE__astra_medium`, `ROLE__astra_high`; high is never an ordinary
recommendation. A definition is not a running agent. Inspect the actual available
targets on the host, not just files on disk. Fixed agent fields can affect native
dispatch precedence; verify requested, configured and reported values separately.
Cursor inherits its runtime selector: do not claim Codex routing parity there.

Native sandbox permissions, connected-tool permissions and declared role boundaries
are not the same. Read-only agent defaults are conservative; QA artifact writes
need a verified isolated artifact workspace/permission arrangement, not product
write access by convenience. If that capability is absent, the principal resolves
the internal preparation/runner handoff without giving the auditor mutation rights.

No causal token/cost advantage is established by the historical audit. Evaluate
comparable analysis packets, retain withheld cases and compare the improved workflow
without Jev, shadow and selective application. Do not use Astra as ground truth.
