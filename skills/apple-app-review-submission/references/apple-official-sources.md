# Official Apple source map

Use these as starting points and verify the live page when the request concerns a real submission or current requirements:

- App Review overview, preparation, timing, expedited reviews, and official links: https://developer.apple.com/app-store/review/
- App Review Guidelines: https://developer.apple.com/app-store/review/guidelines/
- App Review information fields, notes, demo accounts, and What's New: https://developer.apple.com/help/app-store-connect/reference/app-information/platform-version-information
- Submission sequence and the separation between Add for Review and Submit for Review: https://developer.apple.com/help/app-store-connect/manage-submissions-to-app-review/submit-an-app/
- App and submission status definitions: https://developer.apple.com/help/app-store-connect/reference/app-information/app-and-submission-statuses
- Account-deletion requirement and implementation guidance: https://developer.apple.com/support/offering-account-deletion-in-your-app
- App Store review attachments API overview: https://developer.apple.com/documentation/appstoreconnectapi/app-store-review-attachments

Prefer these first-party pages over social posts, forum anecdotes, prior screenshots, or memory. Apple can change requirements and App Store Connect labels; cite the live source in user-facing answers when it supports a current claim.
